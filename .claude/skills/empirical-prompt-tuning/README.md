# empirical-prompt-tuning — プレースホルダ一覧

このスキルにはプロジェクト固有のプレースホルダはありません。

SKILL.md は agent 向けテキスト指示の評価・改善ループを記述したもので、特定のプロジェクト構成に依存しません。そのままコピーして使えます。

## 使うシーン

- skill / slash command / task プロンプト / CLAUDE.md 節 / コード生成プロンプトを新規作成・大幅改訂した直後
- エージェントの挙動が期待通りにならず、原因を指示側の曖昧さに求めたいとき
- 重要度の高い指示（頻繁に使う skill、自動化の中核プロンプト）を堅牢化したいとき

## 前提

- `Task` tool で subagent を dispatch できる環境（バイアス排除読みに必須）
- 評価シナリオ 2〜3 種、要件チェックリストを準備できる

## 関連スキル

- `retrospective-codify` — タスク終了後の学び固定化（プロンプト開発中ではなく事後）
