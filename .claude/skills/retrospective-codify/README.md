# retrospective-codify — プレースホルダ一覧

このスキルにはプロジェクト固有のプレースホルダはありません。

SKILL.md はタスク完了時の学びを ast-grep ルール / skill / CLAUDE.md ルールに固定化する手順を記述したもので、特定のプロジェクト構成に依存しません。

## 使うシーン

- タスク完了直前、またはユーザーから「学びを残して」「ルール化して」と指示されたとき
- 試行錯誤の末に解にたどり着いたとき（初手で詰まった、誤った仮説を立てた、ドキュメント不足で時間を溶かした 等）
- 同種のタスクを将来また行う可能性があるとき

## 前提

- 重複チェック用に `~/.claude/skills/`, `~/.claude/CLAUDE.md`, プロジェクトの `rules/` などを Grep できる
- ast-grep ルールに落とせる場合は `ast-grep-practice` skill を併用
- ユーザー承認なしに CLAUDE.md / skill を更新しないこと（必ず提案 → 承認 → 書き出し）

## 関連スキル

- `empirical-prompt-tuning` — プロンプト開発中の評価ループ（事前）
- `ast-grep-practice` — lint ルール化する場合の書き方とテスト
